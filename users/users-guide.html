GASデプロイ手順

▼

⚠️ GAS構文エラー（ParseError: Unexpected token ;）の恒久防止

Google Apps Script (GAS) の静的JavaScriptパーサーはES2022のクラスフィールド構文（class { props; }）に対応しておらず、未変換のままPushすると構文解析エラーが発生します。

恒久対策: esbuild.config.mjs のビルドターゲットを必ず target: 'es2019' に指定してください。クラスフィールドがコンストラクタ初期化（constructor() { this.props = ...; }）に自動トランスパイルされ、エラーを恒久的に防ぐことができます。

本プロジェクトでは clasp を用いた固定デプロイID運用を採用しています。

  1. 1 初回セットアップ
    • .clasp.json.sample を参考に .clasp.json を作成し、自身のスクリプトIDを設定します。
    • npx clasp login でGoogleアカウントに認証します。
  2. 2 スクリプトプロパティの設定
    • SPREADSHEET_ID: データ保存用GoogleスプレッドシートID（未設定でも内蔵JISデータで稼働）
    • OUTPUT_FOLDER_ID: 出力先ドライブフォルダID
    • ENV: development または production
  3. 3 環境設定ファイル（.env.development）の準備
    • ルートディレクトリに .env.development を作成します（.env.development.sample を複製）： 
      # .env.development
DEPLOYMENT_ID=
  4. 4 初回デプロイとID取得
    • 固定デプロイIDが未設定の状態で初回デプロイを実行します： 
      npm run deploy:gas:dev
    • 初回は新規デプロイが作成され、ターミナル上に発行された Deployment ID（例: AKfycbx...）が表示されます。
    • 発行されたIDを .env.development に記載します： 
      DEPLOYMENT_ID=AKfycbx...（取得したデプロイID）
  5. 5 継続デプロイの実行
    • 以降は同じコマンドを実行するだけで、.env.development に指定されたデプロイIDに対して上書きデプロイが行われ、Web App の URL が固定されます： 
      # 開発環境への上書きデプロイ
npm run deploy:gas:dev

# 本番環境へのデプロイ（.env.production の DEPLOYMENT_ID を使用）
npm run deploy:gas:prod
  6. 6 Web App URLの確認と動作検証
    • デプロイ完了時に出力される Web App URL（または npx clasp deployments で確認）へアクセスします。
    • ブラウザで Web UI 画面が表示されるか確認します（doGet の疎通）。
    • Autodesk Fusion アドインや外部クライアントから Webhook / JSON POST（doPost）が正常に応答するか検証します。
